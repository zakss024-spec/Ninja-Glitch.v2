NINJA GLITCH v2
================

Mobile-first cyber/neon UI inspired by the supplied reference video.

FILES
- index.html
- style.css
- script.js
- assets/

SAFETY
This project is a visual/simulation interface. Network Lab, Wi-Fi Lab, OTP Lab,
OSINT and RAT Lab do not perform real attacks, send OTP spam, disconnect devices,
access accounts, or control remote devices.

DEPLOY
Upload the whole folder to GitHub. Vercel can deploy it as a static site.
No build command is required.
